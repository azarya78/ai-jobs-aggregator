# ai-jobs-aggregator
### Staging requirements evidence

An optional `requirementsEvidence` array contains short source-text excerpts about the role's language, subject area, or qualifications. It can be empty and is not an exhaustive list. Geographic eligibility is reported independently in `eligibilityClass`. `lastVerifiedAt` records observation on the source board, not a completed application. A non-numeric per-task payment can have a unit with null minimum and maximum amounts.
